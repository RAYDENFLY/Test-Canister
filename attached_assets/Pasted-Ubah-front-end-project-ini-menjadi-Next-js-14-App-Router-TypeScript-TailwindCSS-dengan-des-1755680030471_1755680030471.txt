Ubah front-end project ini menjadi **Next.js 14 (App Router) + TypeScript + TailwindCSS** dengan desain **elegan premium ala Wordpress modern theme (ThemeForest style)**, bukan dashboard kaku template. Buat UI terasa crafted, bukan AI generic. Fokus ke detail visual.

===== GUIDELINES DESAIN =====
- Style: Modern, elegan, airy, seperti Wordpress premium theme + sedikit sentuhan SaaS startup.
- Layout: Sidebar kiri (floating glass card) + header minimal + main content fluid dengan section bergaya cards, tetapi tidak monoton.
- Theme: Dark + gradient elegan, bukan polos.
  - Base background: radial gradient (biru tua #0E1117 → ungu tua #1A103D).
  - Glass panels: bg-white/5 backdrop-blur-lg rounded-2xl border border-white/10 shadow-[0_8px_32px_rgba(0,0,0,.4)].
  - Primary accent: gradient linear(90deg, #38BDF8, #6366F1).
  - Secondary accent: gradient linear(90deg, #10B981, #F59E0B).
  - Text utama: #F3F4F6 (gray-100), sekunder #9CA3AF.
- Typography: gunakan font **"Inter"** atau system-ui; judul besar bold, subjudul medium, body ringan. Spacing longgar.
- Animasi: Halus, elegan, gunakan framer-motion. Hover cards → scale 1.02 + subtle glow. Links → underline animasi.
- Iconography: lucide-react icons, tapi kecil elegan. Warna sesuai accent.

===== DETAIL PER PAGE =====
- Dashboard:
  - Hero section dengan heading besar “Welcome back, [username]” + subteks.
  - 4 StatCard dengan animasi masuk (metric & icon).
  - ActivityFeed list (glass card, scrollable).
  - Grid Quick Job Recommendations (JobCard elegan).
- Job Board:
  - Filter bar atas (search box, kategori dropdown).
  - Responsive grid JobCard.
- Chat:
  - Glass chat window; pesan bubble rounded-xl.
  - User messages align right (gradient accent), bot messages align left (glass white/10).
  - Input fixed bawah.
- Analytics:
  - Grid 3 metric cards.
  - Glass chart container (placeholder chart, pakai recharts).
- Profile:
  - ProfileForm dengan avatar, input (Display name, skills, bio), tombol Save.

===== EKSTRA UI DETAIL =====
- Sidebar:
  - Logo “DecentWork” gradient text.
  - Nav links dengan icon + label, active state: gradient bg + glow.
- Header:
  - Minimal, kanan ada avatar user (glass circle).
- Cards:
  - Gunakan gradient border subtle, shadow lembut, hover elevate.

===== TEKNIS =====
- Gunakan Tailwind + framer-motion.
- Tailwind config: extend gradient warna brand (blue→violet, green→amber).
- Tambahkan utility .glass di globals.css: bg-white/5 backdrop-blur border border-white/10.
- Semua page full responsive (mobile → sidebar jadi bottom nav glass).
- Pastikan tidak ada import error. Semua file harus self-contained, jalan dengan `npm i && npm run dev`.
